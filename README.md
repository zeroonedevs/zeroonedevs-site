# ZeroOne CodeClub Website

Minimal official website for **ZeroOne CodeClub** under **KL SAC**.

## Stack

- Next.js (App Router)
- Tailwind CSS
- Black + Blue minimal theme

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

This project is configured for static export via Next.js (`output: "export"`).
